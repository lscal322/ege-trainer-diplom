Тренажёр ЕГЭ — дипломный проект

Приложение Flask с интерфейсом на русском. Веб-сервис использует
PostgreSQL; локальный SQLite-снимок нужен для тестов и добавления учебного контента.
React-шаблон не используется для работы приложения: веб-сервис обслуживает Gunicorn.


Четыре предмета, тесты обеих частей, экзамен с таймером, тренировка по номеру
задания, адаптивная практика, банк ошибок, аналитика, рейтинг, сочинения,
однократная повторная отправка после проверки, новости и кабинет преподавателя.
Учебный банк не является полноценным официальным вариантом КИМ. Процент
правильных ответов — внутренний
показатель тренажёра, не официальный тестовый балл ЕГЭ. Самопроверка сочинения
по русскому использует критерии К1–К10 и максимум 22 балла. Это чек-лист и
ручная проверка, не автоматический анализ сочинения.
Для остальных предметов развёрнутые ответы используют учебную шкалу,
не официальную предметную.
